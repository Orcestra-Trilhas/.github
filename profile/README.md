# Bem-vindo(a) à Nossa Organização de Capacitação!

Este é o ambiente oficial criado exclusivamente para armazenar e avaliar as atividades da nossa trilha de desenvolvimento. O nosso foco principal é o versionamento colaborativo e a revisão de código em equipe.

## Nossas Trilhas de Desenvolvimento
Atualmente, a organização abriga as seguintes trilhas de capacitação para os membros da empresa:
* **BackEnd**
* **FrontEnd**
* **Design (Figma)**
* **DevOps**
* **Gamificação**
* **Mobile**

## Como funciona o nosso fluxo de entregas?
Para garantir a segurança do nosso código e um aprendizado de excelência, adotamos um fluxo de entrega padronizado e seguro:
* **Repositórios Pessoais:** Cada participante recebe acesso ao seu próprio repositório, criado a partir de um template oficial, onde apenas o autor e os Avaliadores/Admins têm acesso.
* **Proteção da Main:** A nossa branch `main` (versão oficial) é blindada. Isso significa que é proibido enviar código diretamente para ela, evitando que a estrutura base seja quebrada.
* **Trabalho Isolado (Branches):** Todo o trabalho de desenvolvimento e resolução de atividades deve ser feito criando ramificações (Branches) isoladas. Adotamos o padrão de nomenclatura focado no desenvolvedor e na funcionalidade, iniciando com `feature/` seguido do nome da trilha e da atividade (ex: `feature/backend-api-login` ou `feature/frontend-landing-page`).
* **Revisão e Aprovação (Pull Requests):** As entregas oficiais das atividades são realizadas exclusivamente através do envio de Pull Requests (pedidos de revisão). Os Avaliadores/Admins testarão a sua atividade e, se estiver tudo certo, o código será unido à `main`. Caso ajustes sejam necessários, os avaliadores deixarão comentários solicitando as correções.

## Ferramentas Necessárias
Antes de iniciar suas entregas, certifique-se de ter o ambiente básico preparado no seu computador:
* **O Programa (Git):** Responsável por gerenciar o versionamento do nosso código localmente.
* **A Plataforma (GitHub):** A rede social onde os projetos vivem e por onde você fará as entregas.
* **O Editor:** Recomendado para programar e realizar os envios de código de forma visual.
